# Submission package

## What is submitted

| File | Role |
|---|---|
| **`report.pdf`** | **The submitted report.** 2 pages including references (the brief allows 2 pages excluding references), LaTeX source in `report.tex` |
| **`PULSE-quantization-deck.pdf`** | Presentation, 15 slides, 25-minute slot |
| `PULSE-quantization-deck.pptx` | Editable deck with speaker notes |
| `supplementary-report.pdf` | Extended 13-page write-up; **not** part of the submission, kept as the engineering record |
| `supplementary-report.docx` | Same, editable |

Both documents are generated by committed scripts (`make_report.py`, `make_deck.py`, and Tectonic
for `report.tex`), and every table names the CSV it came from.

## Headline result

54.688 MB FP32 → **21.677 MB** (**-60.4%**) at a **0.94%** worst-quality-setting penalty and
**+0.48 to +0.55%** BD-rate across Kodak, CLIC Professional and Set14.

The comparison that motivates the work: **uniform INT8 gives a smaller file (13.904 MB) at 26.18%
penalty**, so the mixed assignment is **39x better quality at comparable size**.

| Point | Size | Saving | Kodak | CLIC | Set14 |
|---|---|---|---|---|---|
| 1% budget champion | 21.677 MB | -60.4% | 0.672% | 0.851% | 0.935% |
| 1.8% budget variant | 18.664 MB | -65.9% | 1.268% | 1.595% | 1.601% |
| INT8 tier + QAT 12k | 14.401 MB | -73.7% | 1.848% | 2.874% | 3.363% |

## What fine-tuning contributed

QAT removed **61%, 83% and 98%** of the damage on three hand-chosen assignments, and **exactly 0%**
on the assignment the solver had already optimized. Fine-tuning repairs what an assignment leaves on
the table; an optimal assignment leaves nothing.

## Limitations, stated up front

1. **Checkpoint selection under-reports QAT.** A 6-crop validation probe scored the best INT8 model
   as no better than its start, while the full evaluation shows 8.61% to 3.36%. Saved checkpoints are
   probably not the best available.
2. **Weights only** — activations stay FP32, so W8A8 is not exercised.
3. **4-bit is simulated** (fake quantization): quality is measured, speed is not claimed.
4. **One entropy lane** — the largest unused latency lever, and it changes the bitstream contract.
5. **Single seed, single pool** for QAT: the qualitative finding holds across three tiers and two
   step counts; the exact percentages are single-run values.
6. **The penalty metric is project-defined**; BD-rate is reported alongside so no claim rests on it.
